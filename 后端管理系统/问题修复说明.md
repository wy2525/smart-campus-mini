# 问题修复说明

## 问题分析

### 1. ElMessage 未定义错误

**错误信息**:
```
获取统计数据失败: ReferenceError: ElMessage is not defined
```

**原因**: `src/utils/request.ts` 文件中使用了 `ElMessage` 但没有导入 `element-plus` 库。

**修复方案**:
在 `src/utils/request.ts` 文件顶部添加导入语句：
```typescript
import { ElMessage } from 'element-plus'
```

### 2. API 404 错误

**错误信息**:
```
GET http://localhost:3001/api/admin/statistics/overview 404 (Not Found)
GET http://localhost:3001/api/admin/statistics/users 404 (Not Found)
GET http://localhost:3001/api/admin/statistics/orders 404 (Not Found)
```

**原因**: Vite代理配置的目标端口不正确。后端实际运行在 8082 端口，而代理配置指向了 8080 端口。

**修复方案**:
1. 检查后端实际端口: `netstat -ano | findstr :808`，发现8082端口有进程在监听
2. 检查后端配置: `demo/src/main/resources/application.properties` 中 `server.port=8082`
3. 修改 `vite.config.ts` 中的代理配置：
   ```typescript
   proxy: {
     '/api': {
       target: 'http://localhost:8082',  // 从 8080 改为 8082
       changeOrigin: true,
     },
   }
   ```

### 3. 前端端口配置不一致

**问题**: Vite配置中端口为3000，但实际运行在3001端口

**修复方案**:
将 `vite.config.ts` 中的端口改为3001：
```typescript
server: {
  host: '0.0.0.0',
  port: 3001,  // 从 3000 改为 3001
  proxy: { ... }
}
```

## 启动方式

### 方式一：一键启动（推荐）

```bash
start-all.bat
```

这会自动启动后端（8082端口）和前端（3001端口）服务。

### 方式二：分别启动

**启动后端**:
```bash
cd demo
./start.bat  # Windows
```

**启动前端**:
```bash
cd qianduan
npm run dev
```
