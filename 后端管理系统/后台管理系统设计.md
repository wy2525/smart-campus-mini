# 旅游小程序后台管理系统设计文档

## 一、后台管理API接口

### 1. 用户管理接口

```
GET    /api/admin/users                # 获取用户列表（分页、搜索、筛选）
GET    /api/admin/users/:id            # 获取用户详情
PUT    /api/admin/users/:id            # 更新用户信息
PUT    /api/admin/users/:id/status     # 启用/禁用用户
DELETE /api/admin/users/:id            # 删除用户
GET    /api/admin/users/:id/orders     # 获取用户订单列表
GET    /api/admin/users/:id/guides     # 获取用户发布攻略
```

### 2. 景点管理接口

```
GET    /api/admin/attractions                 # 获取景点列表（分页、搜索、筛选）
GET    /api/admin/attractions/:id             # 获取景点详情
POST   /api/admin/attractions                 # 创建景点
PUT    /api/admin/attractions/:id             # 更新景点信息
DELETE /api/admin/attractions/:id             # 删除景点
PUT    /api/admin/attractions/:id/status      # 上线/下线景点
GET    /api/admin/attractions/:id/tickets    # 获取景点门票类型
PUT    /api/admin/attractions/:id/sort        # 景点排序
```

### 3. 门票管理接口

```
GET    /api/admin/ticket-types               # 获取所有门票类型
GET    /api/admin/attractions/:id/ticket-types # 获取景点门票类型
POST   /api/admin/attractions/:id/ticket-types # 创建门票类型
PUT    /api/admin/ticket-types/:id            # 更新门票类型
DELETE /api/admin/ticket-types/:id            # 删除门票类型
PUT    /api/admin/ticket-types/:id/stock      # 更新库存
PUT    /api/admin/ticket-types/:id/status     # 上架/下架门票类型
```

### 4. 订单管理接口

```
GET    /api/admin/orders                      # 获取订单列表（分页、筛选）
GET    /api/admin/orders/:id                  # 获取订单详情
PUT    /api/admin/orders/:id                  # 更新订单信息
PUT    /api/admin/orders/:id/status           # 更新订单状态
GET    /api/admin/orders/statistics           # 订单统计数据
GET    /api/admin/orders/export               # 导出订单
```

### 5. 攻略管理接口

```
GET    /api/admin/guides                      # 获取攻略列表（分页、筛选）
GET    /api/admin/guides/:id                  # 获取攻略详情
PUT    /api/admin/guides/:id/approve          # 审核通过
PUT    /api/admin/guides/:id/reject           # 审核拒绝
DELETE /api/admin/guides/:id                  # 删除攻略
PUT    /api/admin/guides/:id/status           # 更新状态
```

### 6. 评论管理接口

```
GET    /api/admin/comments                    # 获取评论列表（分页、筛选）
GET    /api/admin/comments/:id                # 获取评论详情
DELETE /api/admin/comments/:id                # 删除评论
PUT    /api/admin/comments/:id/status         # 更新评论状态
```

### 7. Banner管理接口

```
GET    /api/admin/banners                     # 获取Banner列表
GET    /api/admin/banners/:id                 # 获取Banner详情
POST   /api/admin/banners                     # 创建Banner
PUT    /api/admin/banners/:id                 # 更新Banner信息
DELETE /api/admin/banners/:id                 # 删除Banner
PUT    /api/admin/banners/:id/status          # 上线/下线Banner
PUT    /api/admin/banners/:id/sort            # Banner排序
```

### 8. 数据统计接口

```
GET    /api/admin/statistics/overview         # 总览数据统计
GET    /api/admin/statistics/users            # 用户统计（新增、活跃、地域分布）
GET    /api/admin/statistics/orders           # 订单统计（订单量、金额、趋势）
GET    /api/admin/statistics/attractions      # 景点统计（浏览量、预订量）
GET    /api/admin/statistics/guides            # 攻略统计（发布量、互动量）
```

### 9. 系统配置接口

```
GET    /api/admin/config                     # 获取系统配置
PUT    /api/admin/config                     # 更新系统配置
POST   /api/admin/admin/users                # 添加管理员
```

## 三、详细页面说明

### 1. 登录页面 (login/index.vue)
**功能：**
- 手机号/用户名登录
- 密码登录
- 记住密码
- 登录鉴权

**表单字段：**
- username (用户名/手机号)
- password (密码)
- remember (记住密码)

### 2. 数据总览 (dashboard/index.vue)
**功能：**
- 核心数据统计卡片（用户数、订单数、景点数、攻略数）
- 用户增长趋势图（折线图）
- 订单统计图（柱状图）
- 景点热度排行
- 最新订单列表
- 最新攻略列表

**数据展示：**
- 用户总数、今日新增用户
- 订单总数、今日订单量、今日订单金额
- 景点总数、在线景点数
- 攻略总数、待审核攻略数

### 3. 用户管理

#### 3.1 用户列表 (users/index.vue)
**功能：**
- 用户列表展示（分页）
- 搜索（手机号、昵称）
- 筛选（注册时间、状态）
- 启用/禁用用户
- 删除用户
- 查看详情

**表格列：**
- ID、头像、昵称、手机号、性别、注册时间、状态、操作（查看、编辑、禁用/启用、删除）

#### 3.2 用户详情 (users/Detail.vue)
**展示内容：**
- 基本信息（头像、昵称、手机号、性别、注册时间）
- 订单统计（总订单数、待使用、已完成、已退款）
- 攻略统计（发布数、点赞数、收藏数）
- 订单列表
- 发布的攻略列表

#### 3.3 用户订单 (users/Orders.vue)
**功能：**
- 查看指定用户的所有订单
- 搜索、筛选
- 查看订单详情

### 4. 景点管理

#### 4.1 景点列表 (attractions/index.vue)
**功能：**
- 景点列表展示（分页）
- 搜索（景点名称、分类）
- 筛选（分类、状态、价格区间）
- 新增景点
- 编辑景点
- 上线/下线
- 删除景点
- 查看详情
- 管理门票类型

**表格列：**
- ID、封面图、名称、分类、最低价格、评分、浏览量、状态、排序、操作

#### 4.2 景点表单 (attractions/Form.vue)
**表单字段：**
- 基本信息：名称、分类、封面图、图片集（多图上传）
- 详细信息：介绍、地址、经纬度（地图选点）、联系电话、开放时间、注意事项
- 标签设置：标签选择
- 其他：排序、状态

#### 4.3 景点详情 (attractions/Detail.vue)
**展示内容：**
- 景点基本信息
- 图片轮播
- 门票类型列表
- 浏览量统计
- 预订量统计
- 关联攻略

#### 4.4 门票类型管理 (attractions/Tickets.vue)
**功能：**
- 门票类型列表
- 新增门票类型
- 编辑门票类型
- 上下架
- 调整库存
- 删除

**表格列：**
- 门票名称、描述、价格、库存、状态、排序、操作

### 5. 订单管理

#### 5.1 订单列表 (orders/index.vue)
**功能：**
- 订单列表展示（分页）
- 搜索（订单号、景点名称、用户手机号）
- 筛选（订单状态、下单时间、游玩日期）
- 导出订单（Excel）
- 查看订单详情
- 更新订单状态
- 订单统计

**表格列：**
- 订单号、景点、门票类型、数量、总价、游玩日期、用户信息、订单状态、下单时间、操作

#### 5.2 订单详情 (orders/Detail.vue)
**展示内容：**
- 订单基本信息
- 景点信息
- 门票信息
- 游客信息
- 订单状态流转记录
- 退款信息（如已退款）

#### 5.3 订单统计 (orders/Statistics.vue)
**功能：**
- 订单量统计（日、周、月、年）
- 订单金额统计
- 订单状态分布（饼图）
- 热门景点排行
- 门票类型分布

### 6. 攻略管理

#### 6.1 攻略列表 (guides/index.vue)
**功能：**
- 攻略列表展示（分页）
- 搜索（标题、作者）
- 筛选（审核状态、发布时间）
- 查看详情
- 审核通过/拒绝
- 删除攻略

**表格列：**
- 封面图、标题、作者、浏览量、点赞数、评论数、审核状态、发布时间、操作

#### 6.2 攻略详情 (guides/Detail.vue)
**展示内容：**
- 攻略基本信息
- 攻略内容（富文本）
- 图片展示
- 作者信息
- 数据统计（浏览、点赞、收藏、评论）
- 评论列表

#### 6.3 攻略审核 (guides/Audit.vue)
**功能：**
- 待审核攻略列表
- 快速审核通过/拒绝
- 批量审核

**审核操作：**
- 通过（可选择推荐）
- 拒绝（填写拒绝原因）

### 7. 评论管理

#### 7.1 评论列表 (comments/index.vue)
**功能：**
- 评论列表展示（分页）
- 搜索（评论内容、用户昵称）
- 筛选（攻略ID、时间）
- 删除评论
- 批量删除

**表格列：**
- ID、用户、攻略、评论内容、点赞数、发布时间、操作

### 8. Banner管理

#### 8.1 Banner列表 (banners/index.vue)
**功能：**
- Banner列表展示
- 新增Banner
- 编辑Banner
- 拖拽排序
- 上下架
- 删除

**字段：**
- 标题、图片URL、关联景点、跳转链接、排序、状态

### 9. 系统管理

#### 9.1 系统配置 (system/Config.vue)
**功能：**
- 查看系统配置
- 修改系统配置

**配置项：**
- 网站名称、Logo
- 联系电话
- 退款规则
- 订单超时时间
- 其他自定义配置

#### 9.2 管理员管理 (system/Admins.vue)
**功能：**
- 管理员列表
- 新增管理员
- 修改管理员权限
- 删除管理员
- 重置密码

## 八、订单状态说明

### 订单状态流转
```
unpaid (未支付) → toUse (待使用) → used (已使用) → completed (已完成)
                   ↓
                refunded (已退款)
                   ↓
                cancelled (已取消)
```

### 状态说明
- **unpaid**: 待支付（用户下单后，未完成支付）
- **toUse**: 待使用（已支付，未使用）
- **used**: 已使用（用户已使用门票）
- **completed**: 已完成（已完成评价或流程结束）
- **refunded**: 已退款
- **cancelled**: 已取消（未支付超时取消）
