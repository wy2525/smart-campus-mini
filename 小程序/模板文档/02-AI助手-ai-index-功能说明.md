# AI助手模板 - pages/ai/index

## 页面概述
AI助手是一个智能聊天界面，用户可以与旅游助手进行对话，获取旅游咨询、景点推荐等服务。

## 页面布局

```
┌─────────────────────────────────┐
│  🤖 智能旅游助手 [清空]         │
├─────────────────────────────────┤
│  👤 你好！                      │
│     10:30                       │
│                                 │
│  🤖 欢迎使用智能旅游助手！      │
│     我可以帮您：                │
│     - 推荐旅游景点              │
│     - 解答旅游问题              │
│     - 制定旅行计划              │
│     10:31                       │
│                                 │
│  [更多聊天消息...]              │
│                                 │
│  ⚙️ 正在输入...                │
├─────────────────────────────────┤
│  [请输入您的问题...] [发送]     │
└─────────────────────────────────┘
```

## 交互元素

### 1. 聊天头部
- **位置：** 顶部固定
- **内容：**
  - AI头像（🤖）
  - AI名称：智能旅游助手
  - 在线状态
  - 清空按钮
- **事件：** `bindtap="clearChat"`

### 2. 消息列表
- **位置：** 头部和输入框之间
- **功能：** 显示对话历史
- **消息类型：**
  - 用户消息（右侧，蓝色背景）
  - AI消息（左侧，灰色背景）
  - 系统消息（居中，小字体）
- **滚动：** 自动滚动到底部

### 3. 正在输入提示
- **位置：** 消息列表底部
- **样式：** 三个点动画
- **显示条件：** `isTyping === true`

### 4. 输入区域
- **位置：** 底部固定
- **组件：**
  - 输入框（可多行）
  - 发送按钮（有内容时高亮）
- **事件：**
  - `bindinput="onInput"` - 实时输入
  - `bindconfirm="onKeyboardConfirm"` - 键盘回车
  - `bindtap="sendMsg"` - 点击发送

## 数据字段

### 1. messages（消息列表）
```javascript
[
  {
    id: Number,           // 消息ID
    type: String,         // 消息类型：'user' | 'ai' | 'system'
    content: String,      // 消息内容
    timestamp: String     // 时间戳（格式：HH:mm）
  }
]
```

### 2. 输入相关
```javascript
{
  inputValue: String,     // 输入框内容
  scrollTop: Number,     // 滚动位置
  isTyping: Boolean      // AI是否正在输入
}
```

## 核心功能

### 1. 发送消息
```javascript
sendMsg()
```
- 获取输入内容
- 添加用户消息到列表
- 清空输入框
- 调用AI接口
- 显示输入提示

### 2. 接收AI回复
```javascript
receiveAiResponse(content)
```
- 添加AI消息到列表
- 滚动到底部
- 停止输入提示

### 3. 清空聊天
```javascript
clearChat()
```
- 确认清空操作
- 清空消息列表
- 重置为初始状态

### 4. 自动滚动
```javascript
scrollToBottom()
```
- 滚动消息列表到最新消息
- 带动画效果

## API接口

### 发送消息
```
POST /api/ai/chat
```
**请求：**
```json
{
  "message": "推荐一个北京的景点"
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "reply": "我推荐您游览故宫博物院...",
    "timestamp": "2026-01-14 10:30:00"
  }
}
```

## 注意事项

1. **消息长度限制**：单条消息建议不超过500字
2. **敏感词过滤**：对用户输入进行内容审核
3. **接口超时**：设置合理的超时时间（如30秒）
4. **错误处理**：网络错误时显示提示，允许重试
5. **隐私保护**：聊天记录加密存储

## 数据持久化

### 本地存储
```javascript
// 保存聊天记录
wx.setStorageSync('chatHistory', messages)

// 读取聊天记录
const chatHistory = wx.getStorageSync('chatHistory') || []

// 清空聊天记录
wx.removeStorageSync('chatHistory')
```

### 云端存储
- 可选择将聊天记录同步到服务器
- 支持多设备同步
- 需要用户登录授权

## 性能优化

1. **消息虚拟滚动**：消息过多时使用虚拟滚动
2. **图片懒加载**：AI回复中的图片延迟加载
3. **分页加载**：历史消息分页加载
4. **防抖处理**：输入框输入防抖处理
5. **消息压缩**：历史消息可压缩存储
