# 首页模板 - pages/home/index

## 页面概述
首页是小程序的入口页面，展示景点推荐、热门景点、快捷入口等核心功能，为用户提供浏览和搜索景点的起点。

## 页面布局

```
┌─────────────────────────────────┐
│  搜索栏（点击跳转搜索页）        │
├─────────────────────────────────┤
│  轮播图区域（自动轮播）          │
├─────────────────────────────────┤
│  快捷入口（6个图标）             │
├─────────────────────────────────┤
│  热门景点（横向滚动）            │
├─────────────────────────────────┤
│  为你推荐（纵向列表）            │
└─────────────────────────────────┘
```

## 交互元素

### 1. 搜索栏
- **位置：** 顶部
- **功能：** 点击跳转到搜索页面
- **样式：** 圆角搜索框，带搜索图标
- **事件：** `bindtap="onSearchTap"`

### 2. 轮播图
- **位置：** 搜索栏下方
- **功能：** 展示推广图片，自动轮播
- **属性：**
  - `indicator-dots`: 显示指示点
  - `autoplay`: 自动播放
  - `interval`: 5000ms
  - `duration`: 500ms
- **事件：** `bindtap="onBannerTap"` - 跳转到对应景点

### 3. 快捷入口
- **位置：** 轮播图下方
- **布局：** 3列×2行网格
- **入口类型：**
  1. 热门景点
  2. 周边游
  3. 亲子游
  4. 博物馆
  5. 主题乐园
  6. 攻略精选
- **事件：** `bindtap="onQuickAccessTap"`

### 4. 热门景点
- **位置：** 快捷入口下方
- **布局：** 横向滚动列表
- **展示内容：**
  - 景点封面图
  - 景点名称
  - 价格标签
  - 评分
  - 标签
- **事件：** `bindtap="onHotAttractionTap"`

### 5. 为你推荐
- **位置：** 热门景点下方
- **布局：** 纵向列表
- **展示内容：** 同热门景点

## 数据字段

### 1. bannerList（轮播图数据）
```javascript
[
  {
    id: Number,           // 轮播图ID
    image: String,        // 图片URL
    title: String,        // 标题
    url: String           // 跳转链接
  }
]
```

### 2. hotAttractions（热门景点数据）
```javascript
[
  {
    id: Number,           // 景点ID
    name: String,         // 景点名称
    image: String,        // 封面图URL
    price: String,        // 价格（如"40"或"免费"）
    rating: Number,       // 评分（0-5）
    tags: Array<String>   // 标签数组（如["必玩", "文化"]）
  }
]
```

### 3. recommendAttractions（推荐景点数据）
```javascript
[
  {
    id: Number,           // 景点ID
    name: String,         // 景点名称
    image: String,        // 封面图URL
    price: String,        // 价格
    rating: Number,       // 评分
    tags: Array<String>   // 标签数组
  }
]
```

### 4. quickAccess（快捷入口数据）
```javascript
[
  {
    id: Number,           // 入口ID（1-6）
    name: String,         // 入口名称
    icon: String          // 图标路径
  }
]
```

## 核心功能

### 1. 首页数据加载
```javascript
loadHomeData()
```
- 从服务器获取轮播图数据
- 加载热门景点列表
- 加载推荐景点列表
- 失败时使用模拟数据

### 2. 下拉刷新
```javascript
onPullDownRefresh()
```
- 触发下拉刷新动画
- 重新加载首页数据
- 停止刷新动画

### 3. 登录状态检查
```javascript
checkLoginStatus()
```
- 检查本地存储的token和userInfo
- 更新全局登录状态
- 未登录允许浏览

### 4. 景点跳转
- 点击轮播图 → 跳转到对应景点详情
- 点击热门景点 → 跳转到景点详情
- 点击推荐景点 → 跳转到景点详情
- 点击快捷入口 → 跳转到对应分类列表

## API接口

### 1. 获取轮播图
```
GET /api/banners
```
**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "春节特惠",
      "imageUrl": "/images/banner1.jpg",
      "attractionId": 1
    }
  ]
}
```

### 2. 获取热门景点
```
GET /api/attractions/hot
```
**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "name": "故宫博物院",
      "coverImage": "/images/attraction1.jpg",
      "minPrice": 40,
      "averageRating": 4.8,
      "tags": "必玩,文化"
    }
  ]
}
```

### 3. 获取推荐景点
```
GET /api/attractions/recommend
```
**响应格式同热门景点**

### 数据流验证
1. **轮播图数据加载**
   - API请求 → 数据解析 → 页面渲染
   - 失败时降级到模拟数据

2. **景点数据加载**
   - 热门景点 API → 标签解析 → 渲染
   - 推荐景点 API → 同上

3. **跳转逻辑**
   - 传递景点ID到详情页
   - URL格式：`/pages/attractions/detail?id=1`

## 样式特点

- **整体风格：** 简洁现代，白色背景
- **主色调：** #00bcd4（青色）
- **圆角设计：** 搜索框、卡片、按钮均使用圆角
- **阴影效果：** 卡片使用轻微阴影提升层次感
- **间距：** 统一的边距和间距设计

## 注意事项

1. **图片懒加载：** 景点图片较多，建议使用懒加载优化性能
2. **轮播图数量：** 建议3-5张，过多影响体验
3. **热门景点数量：** 建议6-8个，横向滚动体验最佳
4. **推荐景点数量：** 分页加载，避免一次性加载过多
5. **错误处理：** API失败时要有友好的降级方案

## 扩展建议

1. **个性化推荐**：基于用户浏览历史推荐景点
2. **定位功能**：根据用户位置推荐周边景点
3. **活动标签**：展示限时优惠、新品上线等活动标签
4. **动画效果**：添加进入动画提升用户体验
5. **缓存策略**：缓存首页数据减少请求频率
