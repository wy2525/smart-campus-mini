# 景点详情模板 - pages/attractions/detail

## 页面概述
景点详情页面展示景点的详细信息，包括图片轮播、基本信息、门票预订、开放时间、地图导航等，是用户了解景点和进行预订的核心页面。

## 交互元素

### 1. 导航栏
- **位置：** 顶部
- **组件：**
  - 返回按钮
  - 景点名称
- **事件：** `bindtap="onBack"`

### 2. 轮播图
- **位置：** 导航栏下方
- **功能：** 展示景点多张图片
- **属性：**
  - `indicator-dots`: 显示指示点
  - `autoplay`: 关闭自动播放
  - `duration`: 500ms
- **事件：** `bindchange="onSwiperChange"`
- **指示器：** 当前页/总页数

### 3. 基础信息区域
- **景点名称**：大字体显示
- **评分**：星星图标 + 数字
- **地址**：定位图标 + 地址文本
- **距离**：距离用户的位置

### 4. 标签区域
- **展示：** 景点特色标签
- **样式：** 圆角标签
- **点击：** 可点击筛选同类景点

### 5. 门票预订区域
- **价格：** ¥XX 起
- **按钮：** "立即预订"
- **事件：** `bindtap="bookTicket"`

### 6. 信息卡片
- **景点介绍**：详细描述
- **开放时间**：营业时间
- **联系电话**：客服电话（可点击拨打）
- **注意事项**：参观须知

### 7. 地图导航
- **地图图标**：🗺️
- **按钮：** "前往导航"
- **事件：** `bindtap="navigateToMap"`

### 8. 相关攻略
- **列表：** 相关旅游攻略
- **事件：** `bindtap="onGuideTap"` - 跳转到攻略详情

### 9. 底部操作栏
- **分享按钮**：分享给好友
- **收藏按钮**：收藏景点
- **评论按钮**：查看评论

### 10. 分享模态框
- **触发：** 点击分享按钮
- **选项：**
  - 好友
  - 朋友圈
  - 复制链接
- **事件：** 点击选项执行分享

## 数据字段

### 1. 景点基本信息
```javascript
{
  attraction: {
    id: Number,              // 景点ID
    name: String,            // 景点名称
    rating: Number,          // 评分（0-5）
    address: String,         // 地址
    distance: String,        // 距离（如"5.2km"）
    tags: Array<String>,     // 标签数组
    description: String,     // 景点介绍
    openingHours: String,    // 开放时间
    phone: String,           // 联系电话
    notices: String,         // 注意事项
    minPrice: Number,        // 最低价格
    images: Array<String>    // 图片数组
  }
}
```

### 2. 轮播图状态
```javascript
{
  currentIndex: Number       // 当前图片索引
}
```

### 3. 相关攻略
```javascript
{
  relatedGuides: [
    {
      id: Number,            // 攻略ID
      title: String,         // 攻略标题
      author: String,        // 作者
      likes: Number,         // 点赞数
      comments: Number       // 评论数
    }
  ]
}
```

### 4. 交互状态
```javascript
{
  showShareModal: Boolean,   // 是否显示分享弹窗
  isCollected: Boolean,      // 是否已收藏
  collectedCount: Number     // 收藏数
}
```

## 核心功能

### 1. 加载景点详情
```javascript
loadAttractionDetail()
```
- 获取景点ID
- 请求景点详情API
- 解析图片、标签等信息
- 渲染页面

### 2. 轮播图切换
```javascript
onSwiperChange(e)
```
- 更新当前索引
- 更新指示器显示

### 3. 预订门票
```javascript
bookTicket()
```
- 跳转到门票选择页面
- URL格式：`/pages/attractions/ticket?id=${id}`

### 4. 地图导航
```javascript
navigateToMap()
```
- 打开微信地图
- 定位到景点
- 开始导航

### 5. 收藏景点
```javascript
collectAttraction()
```
- 切换收藏状态
- 更新收藏数
- 同步到服务器

### 6. 查看评论
```javascript
viewComments()
```
- 跳转到评论页面
- 显示所有评论

### 7. 分享景点
```javascript
shareAttraction(type)
```
- 显示分享弹窗
- 执行分享操作
- 更新分享统计

## API接口

### 1. 获取景点详情
```
GET /api/attractions/detail
```
**请求参数：**
```javascript
{
  id: Number              // 景点ID
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "id": 1,
    "name": "故宫博物院",
    "description": "中国明清两代的皇家宫殿，位于北京中轴线的中心...",
    "address": "北京市东城区景山前街4号",
    "latitude": 39.9163,
    "longitude": 116.3972,
    "coverImage": "/images/attraction1.jpg",
    "images": [
      "/images/attraction1.jpg",
      "/images/attraction2.jpg",
      "/images/attraction3.jpg"
    ],
    "minPrice": 40,
    "averageRating": 4.8,
    "tags": "必玩,文化,历史",
    "openingHours": "08:30-17:00（4月-10月）\n08:30-16:30（11月-3月）",
    "notices": "1. 需提前购票\n2. 周一闭馆（法定节假日除外）",
    "phone": "010-85007421"
  }
}
```

### 2. 收藏景点
```
POST /api/attractions/collect
```
**请求：**
```json
{
  "attractionId": 1,
  "action": "collect"  // or "uncollect"
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "collected": true,
    "count": 56
  }
}
```

### 3. 获取相关攻略
```
GET /api/guides/related
```
**请求参数：**
```javascript
{
  attractionId: Number    // 景点ID
}
```
**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "title": "北京三日游攻略",
      "author": "旅行达人",
      "likes": 128,
      "comments": 32
    }
  ]
}
```

## 地图导航

### 地图实现
```javascript
navigateToMap() {
  const { attraction } = this.data
  wx.openLocation({
    latitude: parseFloat(attraction.latitude),
    longitude: parseFloat(attraction.longitude),
    name: attraction.name,
    address: attraction.address,
    scale: 15
  })
}
```

### 电话拨打
```javascript
makePhoneCall() {
  const { attraction } = this.data
  wx.makePhoneCall({
    phoneNumber: attraction.phone
  })
}
```
