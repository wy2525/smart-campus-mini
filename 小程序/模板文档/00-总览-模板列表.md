## 如何跑通项目

### 前置条件
1. MySQL 数据库已安装并运行
2. Node.js 已安装（建议 v14+）
3. 微信开发者工具已安装

### 启动步骤

#### 1. 数据库初始化
```bash
# 执行数据库脚本
mysql -u root -p < database_structure.sql
```

#### 2. 后端服务启动
```bash
cd 后端管理系统
npm install
npm start
```

#### 3. 管理后台启动（可选）
```bash
cd 后端管理系统/admin
npm install
npm run serve
```

#### 4. 小程序启动
- 打开微信开发者工具
- 导入项目目录：`c:/Users/王洋/Desktop/桌面文件/wyh/旅游分享`
- 填写 AppID（测试可用测试号）
- 点击编译

### 接口配置
在小程序 `app.js` 中配置后端接口地址：
```javascript
globalData: {
  baseUrl: 'http://localhost:3000'  // 修改为实际后端地址
}
```

## 技术栈

### 小程序端
- 微信小程序原生框架
- WXML/WXSS/JavaScript
- 微信支付 API

### 后端端
- Node.js + Express
- MySQL 数据库
- JWT 身份验证
- RESTful API

### 管理后台
- Vue 3 + Element Plus
- ECharts 图表
- Axios HTTP 客户端

## 数据库表

共13个核心表：
1. users - 用户表
2. attractions - 景点表
3. ticket_types - 门票类型表
4. ticket_inventory - 门票库存表
5. orders - 订单表
6. order_qrcodes - 订单二维码表
7. guides - 攻略表
8. guide_likes - 攻略点赞表
9. guide_favorites - 攻略收藏表
10. comments - 评论表
11. comment_likes - 评论点赞表
12. banners - Banner 表
13. system_config - 系统配置表
