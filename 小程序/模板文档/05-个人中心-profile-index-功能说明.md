# 个人中心模板 - pages/profile/index

## 页面概述
个人中心页面是用户管理个人信息、订单、收藏等功能的核心页面，提供快速访问各项功能的入口。

## 页面布局

```
┌─────────────────────────────────┐
│  👤                            │
│  用户昵称                      │
│  138****8888                   │
│                     >          │
├─────────────────────────────────┤
│  待使用  已完成  已退款         │
│  3       10      2             │
├─────────────────────────────────┤
│  📋 我的订单          >         │
│  💳 我的门票          >         │

│  📍 浏览历史          >         │
│  📝 我的攻略          >         │
```

## 交互元素

### 1. 用户信息区域
- **位置：** 顶部
- **组件：**
  - 用户头像（左侧）
  - 用户昵称（上方）
  - 手机号（下方，已登录时）
  - 登录提示（未登录时）
  - 右箭头
- **事件：**
  - 已登录：点击跳转到个人信息编辑页
  - 未登录：点击跳转到登录页
- **样式：** 渐变背景

### 2. 订单统计区域
- **位置：** 用户信息下方
- **组件：** 3个统计项
  - 待使用（toUse）
  - 已完成（completed）
  - 已退款（refunded）
- **事件：** `bindtap="onOrderStatTap"` - 跳转到订单页对应标签

### 3. 功能列表
- **位置：** 订单统计下方
- **布局：** 列表形式，带图标和箭头
- **事件：** `bindtap="onItemClick"` - 根据ID跳转对应页面

### 4. 管理员功能
- **位置：** 功能列表下方
- **显示条件：** `isAdmin === true`
- **功能：**
  - 用户管理
  - 景点管理
  - 数据统计
- **事件：** `bindtap="onAdminFeatureClick"`

## 数据字段

### 1. 用户信息
```javascript
{
  isLoggedIn: Boolean,   // 是否已登录
  userInfo: {
    id: Number,           // 用户ID
    nickname: String,    // 昵称
    avatar: String,       // 头像URL
    phone: String         // 手机号（脱敏显示）
  }
}
```

### 2. 订单统计
```javascript
{
  orderStats: {
    toUse: Number,        // 待使用数量
    completed: Number,    // 已完成数量
    refunded: Number      // 已退款数量
  }
}
```

### 3. 功能列表
```javascript
{
  profileItems: [
    {
      id: String,         // 功能ID
      name: String,       // 功能名称
      icon: String,       // 图标
      url: String         // 跳转链接
    }
  ]
}
```

### 4. 管理员功能
```javascript
{
  isAdmin: Boolean,       // 是否管理员
  adminFeatures: [
    {
      id: String,         // 功能ID
      name: String,       // 功能名称
      icon: String,       // 图标
      url: String         // 跳转链接
    }
  ]
}
```

## 核心功能

### 1. 检查登录状态
```javascript
checkLoginStatus()
```
- 检查本地存储的token
- 检查本地存储的userInfo
- 更新登录状态
- 加载用户数据

### 2. 加载订单统计
```javascript
loadOrderStats()
```
- 请求订单统计API
- 更新统计数据
- 实时显示

### 3. 点击订单统计
```javascript
onOrderStatTap(e)
```
- 跳转到订单页面
- 自动选中对应标签
- URL格式：`/pages/profile/orders?tab=${type}`

### 4. 点击功能项
```javascript
onItemClick(e)
```
- 获取功能ID
- 跳转到对应页面
- 检查权限（如需登录）

### 5. 点击管理员功能
```javascript
onAdminFeatureClick(e)
```
- 获取功能ID
- 跳转到管理后台
- 需要管理员权限

## API接口

### 1. 获取用户信息
```
GET /api/user/info
```
**请求头：**
```
Authorization: Bearer {token}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "id": 1,
    "nickname": "旅行达人",
    "avatar": "/images/avatar.jpg",
    "phone": "138****8888",
    "isAdmin": false
  }
}
```

### 2. 获取订单统计
```
GET /api/user/order-stats
```
**响应：**
```json
{
  "success": true,
  "data": {
    "toUse": 3,
    "completed": 10,
    "refunded": 2
  }
}
```

### 3. 检查管理员权限
```
GET /api/user/check-admin
```
**响应：**
```json
{
  "success": true,
  "data": {
    "isAdmin": true,
    "adminRole": "super"
  }
}
```

## 用户场景

### 场景1：查看我的订单
1. 用户打开个人中心
2. 点击"待使用"统计
3. 跳转到订单页面
4. 自动选中"待使用"标签

### 场景2：编辑个人信息
1. 用户点击用户信息区域
2. 跳转到个人信息编辑页
3. 修改昵称和头像
4. 保存更改
5. 返回个人中心，信息已更新

### 场景3：查看我的收藏
1. 用户点击"我的收藏"
2. 跳转到收藏页面
3. 浏览收藏的景点和攻略

### 场景4：管理员管理景点
1. 管理员打开个人中心
2. 看到"管理员功能"区域
3. 点击"景点管理"
4. 跳转到管理后台
5. 管理景点信息
