# 景点列表模板 - pages/attractions/list

## 页面概述
景点列表页面展示符合条件的景点列表，支持分类筛选、搜索、排序等功能，帮助用户快速找到心仪景点。

## 交互元素

### 1. 导航栏
- **位置：** 顶部固定
- **组件：**
  - 返回按钮
  - 页面标题（根据分类动态显示）
- **事件：**
  - 返回按钮：`bindtap="onBack"`

### 2. 搜索框
- **位置：** 导航栏下方
- **功能：** 搜索景点名称或城市
- **事件：**
  - `bindinput="onSearchInput"` - 实时搜索
  - `bindconfirm="onSearchConfirm"` - 回车搜索
  - `bindtap="onSearchTap"` - 点击搜索框

### 3. 筛选栏
- **位置：** 搜索框下方
- **筛选项：**
  - 全部
  - 区域（如：北京市、上海市）
  - 分类（如：博物馆、主题乐园）
  - 价格（如：免费、1-100、100-500）
- **事件：** `bindtap="onFilterTap"`

### 4. 排序栏
- **位置：** 筛选栏下方
- **排序项：**
  - 默认（综合推荐）
  - 价格（升序/降序）
  - 评分（从高到低）
  - 距离（从近到远）
- **事件：** `bindtap="onSortTap"`

### 5. 景点列表
- **布局：** 垂直列表
- **事件：** `bindtap="onAttractionTap"` - 跳转到景点详情

### 6. 筛选弹窗
- **触发：** 点击筛选栏
- **功能：** 选择筛选条件
- **事件：**
  - 确认筛选
  - 重置筛选

### 7. 排序弹窗
- **触发：** 点击排序栏
- **功能：** 选择排序方式
- **事件：** 确认排序

## 数据字段

### 1. 页面参数
```javascript
{
  category: String,      // 分类：hot | nearby | family | museum | park
  keyword: String        // 搜索关键词
}
```

### 2. 景点列表
```javascript
{
  attractions: [
    {
      id: Number,         // 景点ID
      name: String,       // 景点名称
      image: String,      // 封面图URL
      rating: Number,     // 评分（0-5）
      tags: Array<String>, // 标签数组
      desc: String,      // 景点描述
      price: String,      // 价格（如"40"）
      distance: String    // 距离（如"5.2km"）
    }
  ]
}
```

### 3. 筛选条件
```javascript
{
  filter: {
    region: String,       // 区域：all | region1 | region2...
    category: String,     // 分类：all | museum | park...
    price: String        // 价格：all | free | 1-100 | 100-500
  }
}
```

### 4. 排序条件
```javascript
{
  sortBy: String,        // 排序：default | price_asc | price_desc | rating | distance
  sortType: String       // 排序类型
}
```

### 5. 分页信息
```javascript
{
  page: Number,          // 当前页码
  pageSize: Number,      // 每页数量
  total: Number,         // 总数
  hasMore: Boolean      // 是否有更多
}
```

## 核心功能

### 1. 加载景点列表
```javascript
loadAttractions()
```
- 构建请求参数
- 请求景点列表API
- 解析标签和价格
- 渲染列表

### 2. 搜索景点
```javascript
searchAttractions(keyword)
```
- 输入搜索关键词
- 防抖处理
- 请求搜索API
- 更新列表

### 3. 筛选景点
```javascript
filterAttractions(filter)
```
- 选择筛选条件
- 构建筛选参数
- 请求筛选API
- 更新列表

### 4. 排序景点
```javascript
sortAttractions(sortBy)
```
- 选择排序方式
- 构建排序参数
- 请求排序API
- 更新列表

### 5. 点击景点
```javascript
onAttractionTap(index)
```
- 跳转到景点详情页
- URL格式：`/pages/attractions/detail?id=${id}`

### 6. 加载更多
```javascript
loadMore()
```
- 页面触底时触发
- 加载下一页数据
- 追加到列表

## API接口

### 1. 获取景点列表
```
GET /api/attractions/list
```
**请求参数：**
```javascript
{
  category: String,      // 分类：hot | nearby | family | museum | park
  keyword: String,       // 搜索关键词
  region: String,        // 区域
  price: String,         // 价格区间
  sortBy: String,        // 排序：default | price_asc | price_desc | rating | distance
  page: Number,          // 页码
  pageSize: Number       // 每页数量
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "list": [
      {
        "id": 1,
        "name": "故宫博物院",
        "coverImage": "/images/attraction1.jpg",
        "minPrice": 40,
        "averageRating": 4.8,
        "tags": "必玩,文化",
        "description": "中国明清两代的皇家宫殿...",
        "distance": 5.2
      }
    ],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

### 2. 搜索景点
```
GET /api/attractions/search
```
**请求参数：**
```javascript
{
  keyword: String,       // 搜索关键词
  page: Number,          // 页码
  pageSize: Number       // 每页数量
}
```
**响应格式同列表接口**

## 用户场景

### 场景1：浏览热门景点
1. 用户点击首页"热门景点"
2. 进入景点列表页面
3. 标题显示"热门景点"
4. 浏览热门景点列表

### 场景2：搜索北京博物馆
1. 用户在预订页面点击"博物馆"
2. 进入景点列表
3. 输入"北京"
4. 选择"北京市"
5. 查看北京博物馆列表

### 场景3：按价格排序找便宜景点
1. 用户打开景点列表
2. 点击排序栏
3. 选择"价格 ↑"
4. 列表按价格升序排列
5. 找到便宜景点

### 场景4：附近景点推荐
1. 用户开启定位
2. 点击排序栏
3. 选择"距离"
4. 列表按距离排序
5. 查看附近景点
