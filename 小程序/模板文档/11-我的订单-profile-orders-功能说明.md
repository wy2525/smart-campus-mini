# 我的订单模板 - pages/profile/orders

## 页面概述
我的订单页面展示用户的所有订单，支持按状态筛选、查看订单详情、使用门票等功能，是用户管理订单的核心页面。

## 交互元素

### 1. 导航栏
- **位置：** 顶部
- **组件：**
  - 返回按钮
  - 页面标题"我的订单"
- **事件：** `bindtap="onBack"`

### 2. 标签栏（Tab Bar）
- **位置：** 导航栏下方
- **标签：**
  - 全部（activeTab = 'all'）
  - 待使用（activeTab = 'toUse'）
  - 已完成（activeTab = 'completed'）
  - 已退款（activeTab = 'refunded'）
- **事件：** `bindtap="switchTab"`
- **样式：** 选中状态高亮

### 3. 订单卡片
- **布局：** 垂直卡片
- **组件：**
  - 订单号和状态（右上角）
  - 景点图片和名称
  - 门票类型和数量
  - 游玩日期
  - 价格（右侧）
  - 操作按钮
- **事件：**
  - 点击卡片区域 → 查看订单详情
  - 点击"立即使用" → 查看二维码
  - 点击"订单详情" → 查看订单详情

### 4. 操作按钮
- **立即使用**：待使用状态显示，跳转到二维码页面
- **订单详情**：所有状态显示，跳转到订单详情页
- **申请退款**：待使用状态显示（可选）
- **删除订单**：已完成/已退款状态显示（可选）

## 核心功能

### 1. 加载订单列表
```javascript
loadOrders()
```
- 获取当前标签
- 请求订单列表API
- 解析订单信息
- 渲染列表

### 2. 切换标签
```javascript
switchTab(e)
```
- 更新 activeTab 状态
- 清空当前列表
- 重新加载数据

### 3. 查看订单详情
```javascript
viewOrderDetail(e)
```
- 获取订单ID
- 跳转到订单详情页
- URL格式：`/pages/profile/orderDetail?id=${id}`

### 4. 立即使用
```javascript
useTicket(e)
```
- 获取订单ID
- 跳转到二维码页面
- URL格式：`/pages/profile/qrcode?orderId=${id}`

### 5. 申请退款
```javascript
requestRefund(e)
```
- 显示退款确认弹窗
- 确认后请求退款API
- 更新订单状态

### 6. 删除订单
```javascript
deleteOrder(e)
```
- 显示删除确认弹窗
- 确认后请求删除API
- 从列表中移除

## API接口

### 1. 获取订单列表
```
GET /api/orders/list
```
**请求参数：**
```javascript
{
  status: String,           // 订单状态：'all' | 'toUse' | 'completed' | 'refunded'
  page: Number,             // 页码
  pageSize: Number          // 每页数量
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "list": [
      {
        "id": 1,
        "orderNo": "ORD202601140001",
        "status": "toUse",
        "statusText": "待使用",
        "statusColor": "#00bcd4",
        "attraction": {
          "id": 1,
          "name": "故宫博物院",
          "coverImage": "/images/attraction1.jpg"
        },
        "ticketType": "成人票",
        "quantity": 2,
        "ticketDate": "2026-01-20",
        "totalPrice": 120
      }
    ],
    "total": 10,
    "page": 1,
    "pageSize": 10
  }
}
```

### 2. 申请退款
```
POST /api/orders/refund
```
**请求：**
```json
{
  "orderId": 1,
  "reason": "行程变更"
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "orderId": 1,
    "status": "refunded",
    "refundAmount": 120
  }
}
```

### 3. 删除订单
```
DELETE /api/orders/{orderId}
```
**响应：**
```json
{
  "success": true,
  "message": "订单删除成功"
}
```

## 退款流程

### 申请退款
```
点击申请退款 → 确认退款弹窗 → 请求退款API → 更新订单状态 → 退款成功
```

### 退款确认弹窗
```javascript
wx.showModal({
  title: '申请退款',
  content: '确认要申请退款吗？',
  confirmText: '确认退款',
  success: (res) => {
    if (res.confirm) {
      this.requestRefund(orderId)
    }
  }
})
```

### 退款规则
- 游玩日期前7天可全额退款
- 游玩日期前1-7天退款50%
- 游玩当天不可退款
- 已使用的门票不可退款

## 删除订单

### 删除确认
```javascript
wx.showModal({
  title: '删除订单',
  content: '确认要删除该订单吗？',
  confirmText: '确认删除',
  success: (res) => {
    if (res.confirm) {
      this.deleteOrder(orderId)
    }
  }
})
```

### 删除规则
- 只能删除已完成或已退款的订单
- 待使用订单不能删除
- 删除后不可恢复
