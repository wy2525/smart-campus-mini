## 🚀 快速开始

### 1. 环境准备

#### 前置条件
- Node.js v14+
- MySQL 5.7+
- 微信开发者工具
- Git

#### 安装依赖
```bash
# 进入后端目录
cd 后端管理系统

# 安装依赖
npm install

# 启动后端服务
npm start
```

### 2. 数据库初始化

```bash
# 登录MySQL
mysql -u root -p

# 执行数据库脚本
source database_structure.sql

# 或直接执行
mysql -u root -p < database_structure.sql
```

### 3. 配置后端

编辑 `后端管理系统/.env` 文件：
```env
# 服务器配置
PORT=3000
NODE_ENV=development

# 数据库配置
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_DATABASE=travel_share

# JWT密钥
JWT_SECRET=your_jwt_secret_key

# 文件上传
UPLOAD_PATH=./uploads
```

### 4. 启动小程序

1. 打开微信开发者工具
2. 导入项目目录：`c:/Users/王洋/Desktop/桌面文件/wyh/旅游分享`
3. 填写 AppID（测试可用测试号）
4. 点击编译

### 5. 配置小程序接口

编辑 `app.js` 中的后端接口地址：
```javascript
App({
  globalData: {
    baseUrl: 'http://localhost:3000'  // 修改为实际后端地址
  }
})
```

## 🛠️ 常见问题

### Q1: 后端启动失败
**A:** 检查数据库连接配置，确保MySQL服务已启动

### Q2: 小程序请求失败
**A:** 检查baseUrl配置，确保后端服务正常运行

### Q3: 图片无法显示
**A:** 检查图片路径，确保图片文件存在

### Q4: 登录失败
**A:** 检查数据库中是否有用户数据，确保密码正确

### Q5: 订单无法提交
**A:** 检查门票库存，确保库存充足
