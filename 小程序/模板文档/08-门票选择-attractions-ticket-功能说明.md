# 门票选择模板 - pages/attractions/ticket

## 页面概述
门票选择页面是用户选择门票类型和数量的核心页面，提供详细的门票信息、价格展示和数量选择，帮助用户完成购票决策。

## 交互元素

### 1. 导航栏
- **位置：** 顶部
- **组件：**

### 2. 景点信息卡片
- **位置：** 导航栏下方
- **组件：**

  - 景点名称

- **样式：** 卡片样式，阴影效果

### 3. 门票类型列表
- **位置：** 景点信息下方
- **布局：** 垂直列表
- **组件：**

- **事件：** `bindtap="selectTicket"`

### 4. 数量选择器

- **位置：** 底部固定

  tickets: [

### 3. 选择状态
```javascript
{
  selectedTicket: Object,   // 选中的门票类型
  quantity: Number,         // 购买数量
  totalPrice: Number        // 总价
}
```

## 核心功能

### 1. 加载门票类型
```javascript
loadTicketTypes()
```
- 获取景点ID
- 请求门票类型API
- 解析价格和库存
- 渲染列表

### 2. 选择门票类型
```javascript
selectTicket(e)
```
- 获取门票索引
- 更新选中状态
- 重新计算总价

### 3. 增加数量
```javascript
increaseQuantity()
```
- 数量+1
- 检查库存限制
- 检查最大数量限制
- 重新计算总价

### 4. 减少数量
```javascript
decreaseQuantity()
```
- 数量-1
- 检查最小数量限制
- 重新计算总价

### 5. 计算总价
```javascript
calculateTotal()
```
- 单价 × 数量
- 更新总价显示

### 6. 确认选择
```javascript
confirmBooking()
```
- 验证是否已选择门票
- 验证数量是否合法
- 跳转到订单确认页
- 传递门票信息

## API接口

### 1. 获取门票类型
```
GET /api/attractions/ticket-types
```
**请求参数：**
```javascript
{
  attractionId: Number    // 景点ID
}
```
**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "attractionId": 1,
      "name": "成人票",
      "description": "景点全票，包含主要展区",
      "price": 60,
      "stock": 150
    },
    {
      "id": 2,
      "attractionId": 1,
      "name": "学生票",
      "description": "学生专属优惠，需出示学生证",
      "price": 30,
      "stock": 80
    }
  ]
}
```

### 2. 检查库存
```
GET /api/tickets/check-stock
```
**请求参数：**
```javascript
{
  ticketTypeId: Number,   // 门票类型ID
  date: String,          // 游玩日期（YYYY-MM-DD）
  quantity: Number       // 数量
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "available": true,
    "stock": 80
  }
}
```

## 确认跳转

### 跳转逻辑
```javascript
confirmBooking() {
  const { selectedTicket, quantity, attraction } = this.data
  const totalPrice = selectedTicket.price * quantity

  wx.navigateTo({
    url: `/pages/attractions/order?attractionId=${attraction.id}&ticketId=${selectedTicket.id}&quantity=${quantity}&totalPrice=${totalPrice}`
  })
}
```

### 传递参数
- attractionId: 景点ID
- ticketId: 门票类型ID
- quantity: 数量
- totalPrice: 总价

## 用户场景

### 场景1：购买成人票
1. 用户进入门票选择页
2. 查看门票类型
3. 选择"成人票"
4. 设置数量为2
5. 查看总价
6. 点击确认

### 场景2：购买学生票
1. 学生用户进入页面
2. 查看门票类型
3. 发现"学生票"优惠
4. 选择"学生票"
5. 设置数量为1
6. 查看优惠后的价格
7. 点击确认

### 场景3：多张购票
1. 用户购买家庭票
2. 选择"成人票"
3. 数量设为5（超过库存限制）
4. 系统提示最多购买20张
5. 数量设为5
6. 查看总价
7. 点击确认

### 场景4：库存不足
1. 用户想购买热门景点门票
2. 选择门票类型
3. 发现库存为0
4. 显示"库存不足，不可选择"
5. 选择其他门票类型
6. 正常购票
