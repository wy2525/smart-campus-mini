# 预订模板 - pages/bookings/index

## 页面概述
预订页面是用户浏览和预订景点/酒店的主要页面，支持分类切换和列表浏览，提供便捷的预订入口。

## 页面布局

```
┌─────────────────────────────────┐
│  景点  酒店 （Tab切换）          │
├─────────────────────────────────┤
│  ┌─────────────────────────────┐ │
│  │ 图片                         │ │
│  │ 景点名称         ⭐ 4.8      │ │
│  │ [标签1] [标签2]             │ │
│  │ 景点描述...                  │ │
│  │ ¥40 起      [预订]          │ │
│  └─────────────────────────────┘ │
│  ┌─────────────────────────────┐ │
│  │ 图片                         │ │
│  │ 景点名称         ⭐ 4.9      │ │
│  │ [标签1] [标签2]             │ │

│  │ ¥60 起      [预订]          │ │
│  └─────────────────────────────┘ │
│  [更多列表...]                   │
└─────────────────────────────────┘
```

## 交互元素

### 1. 标签栏（Tab Bar）
- **位置：** 顶部固定
- **标签：**
  - 景点（activeTab = 'attractions'）
  - 酒店（activeTab = 'hotels'）
- **事件：** `bindtap="switchTab"`
- **样式：** 选中状态高亮，底部线条

### 2. 列表项
- **布局：** 左图右文
- **组件：**
  - 封面图（左侧）
  - 景点名称（右上）
  - 评分（右上）
  - 标签（名称下方）
  - 描述（标签下方）
  - 价格和预订按钮（底部）
- **事件：** `bindtap="onAttractionTap"` / `bindtap="onHotelTap"`

### 3. 预订按钮
- **位置：** 每个列表项右下角
- **样式：** 青色按钮，圆角
- **事件：** 跳转到景点详情或直接预订

## 数据字段

### 1. tabList（标签列表）
```javascript
[
  {
    id: String,           // 标签ID：'attractions' | 'hotels'
    name: String          // 标签名称
  }
]
```

### 2. attractions（景点列表）
```javascript
[
  {
    id: Number,           // 景点ID
    name: String,         // 景点名称
    image: String,        // 封面图URL
    rating: Number,       // 评分（0-5）
    tags: Array<String>,  // 标签数组
    desc: String,         // 景点描述
    price: String         // 价格（如"40"）
  }
]
```

### 3. hotels（酒店列表）
```javascript
[
  {
    id: Number,           // 酒店ID
    name: String,         // 酒店名称
    image: String,        // 封面图URL
    rating: Number,       // 评分
    tags: Array<String>,  // 标签数组
    price: String         // 每晚价格
  }
]
```

## 核心功能

### 1. 切换标签
```javascript
switchTab(e)
```
- 更新 activeTab 状态
- 切换显示内容（景点/酒店）

### 2. 加载景点列表
```javascript
loadAttractions()
```
- 请求景点列表API
- 解析标签和价格
- 渲染列表

### 3. 加载酒店列表
```javascript
loadHotels()
```
- 请求酒店列表API
- 解析酒店信息
- 渲染列表

### 4. 点击预订
```javascript
onAttractionTap(index)
```
- 跳转到景点详情页
- URL格式：`/pages/attractions/detail?id=${id}`

## API接口

### 1. 获取景点列表
```
GET /api/attractions/list
```
**请求参数：**
```javascript
{
  category: String,     // 分类：hot | nearby | family | museum | park
  page: Number,         // 页码
  pageSize: Number     // 每页数量
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "list": [
      {
        "id": 1,
        "name": "故宫博物院",
        "coverImage": "/images/attraction1.jpg",
        "minPrice": 40,
        "averageRating": 4.8,
        "tags": "必玩,文化",
        "description": "中国明清两代的皇家宫殿..."
      }
    ],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

### 2. 获取酒店列表
```
GET /api/hotels/list
```
**响应格式同景点列表**

## 注意事项

1. **数据量控制**：每页建议10-20条
2. **图片大小**：封面图建议500x500px以内
3. **描述长度**：限制为2-3行，超出省略
4. **标签数量**：最多显示3-4个
5. **价格格式**：统一为"¥XX 起"格式
