# 订单确认模板 - pages/attractions/order

## 页面概述
订单确认页面是用户确认订单信息和提交订单的最终页面，展示订单详情、游客信息、订单编号等关键信息，支持修改和提交订单。

## 数据字段

### 1. 景点信息
```javascript
{
  attraction: {
    id: Number,             // 景点ID
    name: String,           // 景点名称
    image: String          // 封面图URL
  }
}
```

### 2. 门票信息
```javascript
{
  ticket: {
    id: Number,            // 门票类型ID
    name: String,          // 门票名称
    price: Number          // 单价
  }
}
```

### 3. 订单信息
```javascript
{
  orderInfo: {
    date: String,          // 游玩日期（YYYY-MM-DD）
    num: Number,           // 数量
    totalPrice: Number,    // 总价
    orderNo: String,       // 订单编号
    createTime: String     // 下单时间
  }
}
```

### 4. 游客信息
```javascript
{
  passengerInfo: {
    name: String,          // 姓名
    idCard: String,        // 身份证号
    phone: String          // 手机号
  }
}
```

## 核心功能

### 1. 加载订单数据
```javascript
loadOrderData()
```
- 获取URL参数
- 请求订单预览API
- 解析订单信息
- 渲染页面

### 2. 生成订单编号
```javascript
generateOrderNo()
```
- 生成唯一订单编号
- 格式：ORD + 日期 + 序号
- 示例：ORD202601140001

### 3. 修改游玩日期
```javascript
changeDate()
```
- 打开日期选择器
- 选择游玩日期
- 更新订单信息

### 4. 修改游客信息
```javascript
changePassengerInfo()
```
- 打开游客信息编辑页
- 修改游客信息
- 更新订单信息

### 5. 复制订单编号
```javascript
copyOrderNo()
```
- 复制订单编号到剪贴板
- 提示复制成功

### 6. 提交订单
```javascript
submitOrder()
```
- 验证订单信息
- 请求提交订单API
- 跳转到支付页面
- 或跳转到订单详情

### 7. 返回修改
```javascript
goBack()
```
- 返回到门票选择页
- 携带订单信息
- 允许继续修改

## API接口

### 1. 创建订单预览
```
POST /api/orders/preview
```

```json
{
  "attractionId": 1,
  "ticketTypeId": 1,
  "quantity": 2,
  "visitDate": "2026-01-20"
}
```
**响应：**

      "id": 1,

### 2. 提交订单
```
POST /api/orders/create
```
**请求：**
```json
{
  "attractionId": 1,
  "ticketTypeId": 1,
  "visitDate": "2026-01-20",
  "quantity": 2,
  "unitPrice": 60,
  "totalPrice": 120,
  "passengerName": "张三",
  "passengerIdCard": "123456789012345678",
  "passengerPhone": "138****8888"
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "orderId": 1,
    "orderNo": "ORD202601140001",
    "totalPrice": 120,
    "status": "unpaid"
  }
}
```

## 支付流程

### 提交订单后
```
订单提交 → 生成支付参数 → 调用微信支付 → 支付成功 → 更新订单状态 → 跳转到订单详情
```

### 支付参数
```javascript
wx.requestPayment({
  timeStamp: String,
  nonceStr: String,
  package: String,
  signType: 'MD5',
  paySign: String,
  success: (res) => {
    // 支付成功
    wx.navigateTo({
      url: `/pages/profile/paymentSuccess?orderId=${orderId}`
    })
  },
  fail: (res) => {
    // 支付失败
    wx.showToast({
      title: '支付失败',
      icon: 'none'
    })
  }
})
```

## 订单状态

### 订单状态流转
```
unpaid (未支付) → paid (已支付) → used (已使用) → completed (已完成)
                 ↓
              refunded (已退款)
                 ↓
              cancelled (已取消)
```

### 状态说明
- unpaid: 待支付
- paid: 已支付
- used: 已使用
- completed: 已完成
- refunded: 已退款
- cancelled: 已取消

## 超时处理

### 订单超时
- 订单未支付超时时间：30分钟
- 超时后自动取消
- 提示用户订单已取消

### 超时提示
```
订单已超时，请重新下单
```

## 退款规则

### 退款条件
- 游玩日期前7天可退款
- 游玩当天不可退款
- 已使用的门票不可退款

### 退款流程
```
申请退款 → 审核通过 → 退款处理 → 退款完成
```
