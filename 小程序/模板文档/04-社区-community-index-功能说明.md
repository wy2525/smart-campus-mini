# 社区模板 - pages/community/index

## 页面概述
社区页面是用户浏览和分享旅游攻略的平台，展示其他用户发布的攻略，支持点赞、评论、收藏等互动功能。

```

│  推荐  最新  热门  关注         │
├─────────────────────────────────┤
│  ┌─────────────────────────────┐ │
│  │ 👤 用户昵称                  │ │
│  │ 2026-01-14                  │ │
│  │                             │ │

```

## 交互元素

### 1. 标签栏（Tab Bar）
- **位置：** 顶部固定
- **标签：**
  - 推荐（activeTab = 'recommend'）
  - 最新（activeTab = 'newest'）
  - 热门（activeTab = 'hottest'）
  - 关注（activeTab = 'following'）
- **事件：** `bindtap="switchTab"`
- **样式：** 选中状态高亮

### 2. 攻略卡片
- **布局：** 垂直卡片
- **组件：**
  - 头像和作者信息
  - 攻略标题和摘要
  - 封面图
  - 统计数据（点赞、评论、收藏）
- **事件：**
  - 点击卡片 → 查看攻略详情
  - 点击点赞 → 点赞/取消点赞
  - 点击收藏 → 收藏/取消收藏

### 3. 发布按钮
- **位置：** 右下角固定
- **样式：** 圆形按钮，"+"图标
- **事件：** `bindtap="publishGuide"`
- **跳转：** 发布攻略页面

### 4. 下拉刷新
- **组件：** scroll-view 的 refresher 功能
- **事件：** `bindrefresherrefresh="onPullDownRefresh"`
- **状态：** `refresher-triggered="{{refreshing}}"`

## 数据字段

### 1. tabList（标签列表）
```javascript
[
  {
    id: String,           // 标签ID
    name: String          // 标签名称
  }
]
```

### 2. guides（攻略列表）
```javascript
[
  {
    id: Number,           // 攻略ID
    title: String,        // 攻略标题
    summary: String,      // 攻略摘要
    coverImage: String,   // 封面图URL
    createdAt: String,    // 发布时间（格式：YYYY-MM-DD）
    author: {
      id: Number,         // 作者ID
      nickname: String,   // 作者昵称
      avatar: String     // 作者头像
    },
    likes: Number,        // 点赞数
    comments: Number,     // 评论数
    shares: Number,       // 收藏数
    liked: Boolean,       // 当前用户是否点赞
    collected: Boolean    // 当前用户是否收藏
  }
]
```

## 核心功能

### 1. 加载攻略列表
```javascript
loadGuides()
```
- 请求攻略列表API
- 根据当前标签筛选
- 解析作者信息
- 渲染列表

### 2. 切换标签
```javascript
switchTab(e)
```
- 更新 activeTab 状态
- 清空当前列表
- 重新加载数据

### 3. 下拉刷新
```javascript
onPullDownRefresh()
```
- 显示刷新动画
- 重新加载数据
- 停止刷新动画

### 4. 点赞功能
```javascript
onLikeTap(index)
```
- 切换点赞状态
- 更新点赞数
- 同步到服务器

### 5. 收藏功能
```javascript
onCollectTap(index)
```
- 切换收藏状态
- 更新收藏数
- 同步到服务器

### 6. 查看攻略详情
```javascript
onGuideTap(index)
```
- 跳转到攻略详情页
- URL格式：`/pages/community/detail?id=${id}`

## API接口

### 1. 获取攻略列表
```
GET /api/guides/list
```
**请求参数：**
```javascript
{
  type: String,          // 类型：recommend | newest | hottest | following
  page: Number,          // 页码
  pageSize: Number,      // 每页数量
  userId: Number         // 用户ID（关注类型需要）
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "list": [
      {
        "id": 1,
        "title": "北京三日游攻略",
        "summary": "第一天故宫...",
        "coverImage": "/images/guide1.jpg",
        "createdAt": "2026-01-14",
        "author": {
          "id": 1,
          "nickname": "旅行达人",
          "avatar": "/images/avatar1.jpg"
        },
        "likes": 128,
        "comments": 32,
        "shares": 56,
        "liked": false,
        "collected": false
      }
    ],
    "total": 500,
    "page": 1,
    "pageSize": 10
  }
}
```

### 2. 点赞攻略
```
POST /api/guides/like
```
**请求：**
```json
{
  "guideId": 1,
  "action": "like"  // or "unlike"
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "likes": 129,
    "liked": true
  }
}
```

### 3. 收藏攻略
```
POST /api/guides/collect
```
**请求：**
```json
{
  "guideId": 1,
  "action": "collect"  // or "uncollect"
}
```
**响应：**
```json
{
  "success": true,
  "data": {
    "shares": 57,
    "collected": true
  }
}
```

## 注意事项

1. **内容审核**
   - 发布内容需审核
   - 违规内容不予通过
   - 建立审核机制

2. **图片规范**
   - 封面图建议尺寸：16:9
   - 图片大小限制：5MB以内
   - 支持格式：JPG、PNG

3. **字数限制**
   - 标题：20字以内
   - 摘要：100字以内
   - 内容：5000字以内

4. **互动频率**
   - 防止刷赞
   - 防止恶意评论
   - 限制互动频率

5. **隐私保护**
   - 保护用户隐私
   - 敏感信息脱敏
   - 数据加密存储

## 用户场景

### 场景1：浏览热门攻略
1. 用户打开社区页面
2. 点击"热门"标签
3. 浏览热门攻略列表
4. 感兴趣的点击查看详情

### 场景2：关注用户攻略
1. 用户点击"关注"标签
2. 查看关注用户的最新攻略
3. 发现感兴趣的内容
4. 点赞或收藏

### 场景3：发布新攻略
1. 用户点击右下角"+"按钮
2. 进入发布页面
3. 编辑攻略内容
4. 选择关联景点
5. 提交审核

### 场景4：搜索攻略
1. 用户使用搜索功能
2. 输入关键词
3. 查看搜索结果
4. 找到想要的攻略
